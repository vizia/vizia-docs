1/// The DPI scaling policy of the window.

12/// Controls how often the window's frame loop is driven.
13///
14/// Only [`FramePolicy::Continuous`] is currently offered. `OnDemand` requires a
15/// working sync-effect waker so that off-thread `SyncSignal` writes and disposals
16/// can wake the event loop; without one those updates would stall indefinitely.
17#[derive(Default, Debug, Clone, Copy, PartialEq, Eq)]
18pub enum FramePolicy {
19    /// Drive a frame every vsync interval.
20    ///
21    /// This doesn't force a redraw of the window every frame. It only ensures
22    /// `on_idle` is called on every sync frame; the vizia app decides whether
23    /// anything has to be redrawn based on its reactive system.
24    #[default]
25    Continuous,
26    /// Drive a frame only when there is work to do (events, wakers, animations, timers).
27    OnDemand,
28}
